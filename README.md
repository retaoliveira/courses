# courses

## Compatibilidade das apresentações

As apresentações Xaringan/remark incorporadas a partir do GitHub Pages recebem
controles auxiliares no Safari. Antes de usar as setas do teclado, selecione
**Ativar navegação dos slides**. O controle transfere o foco para o documento da
apresentação; **Abrir em nova aba** permanece disponível como alternativa.

A implementação está em `assets/js/presentation-frames.js` e
`assets/css/presentation-frames.css` e é carregada globalmente pelos parâmetros
`plugins_js` e `plugins_css`.
